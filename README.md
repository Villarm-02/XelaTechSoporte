# XelaTech Soporte

Aplicación de consola en C# para registrar la recepción, el diagnóstico y la reparación de equipos en el centro de soporte XelaTech.

Proyecto de aplicación 02 del curso Programación Avanzada (Fase 2: implementación).

## Cómo ejecutarlo

1. Abrir `XelaTechSoporte.sln` en Visual Studio 2022 o 2026.
2. Compilar y ejecutar con F5.

También se puede ejecutar desde la terminal con `dotnet run --project XelaTechSoporte`.

## Requisitos

- .NET 10
